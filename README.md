# Vinheria Agnello

## Páginas do site

- Início: apresentação da vinheria, seus diferenciais e cuidados com o armazenamento.
- Nossa história: trajetória da empresa e sua entrada no ambiente digital.
- Produtos: categorias de vinhos e tabela com exemplos de produtos e preços fictícios.
- Harmonização: sugestões para combinar vinhos com alimentos e diferentes ocasiões.
- Contato: formulário simples com nome, e-mail e mensagem.

## Recursos utilizados

- HTML para organizar o conteúdo.
- CSS para definir cores, fontes, espaçamentos e adaptar o layout a telas menores.
- Menu de navegação presente nas cinco páginas.
- Imagens ilustrativas, títulos, parágrafos e listas.
- Tabela para apresentar os produtos.
- Formulário com campos obrigatórios e labels.
- Tags semânticas, como header, nav, main, section e footer.
- Meta tags de descrição e palavras-chave.
- Links internos e link externo para a Embrapa Uva e Vinho.
- Espaço para incorporar um vídeo do YouTube na página inicial.

## Organização dos arquivos

- `index.html`: página inicial.
- `src/pages/`: quatro páginas adicionais.
- `src/css/style.css`: estilos compartilhados pelas páginas.
- `src/assets/imgs/`: imagens do site.
- `src/js/`: pasta reservada para futuras funcionalidades.
- `README.md`: documentação do projeto.

## Como abrir o projeto

Baixe ou clone o repositório e abra o arquivo `index.html` no navegador.

Também é possível abrir a pasta no VS Code e utilizar a extensão Live Server.

## Uso de inteligência artificial

O projeto contou com o apoio do ChatGPT na elaboração de organização do conteúdo, explicações para o desenvolvimento e criação das imagens ilustrativas.

A ferramenta foi utilizada como apoio ao aprendizado.
